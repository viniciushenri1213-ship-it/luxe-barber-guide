# Luxe Barber Guide

Crie um site profissional e moderno para uma barbearia fictícia chamada Blackwood Barber.

Estilo visual:

Design elegante, masculino e minimalista.

Cores preto, branco e dourado.

Tipografia sofisticada.

Layout responsivo para computadores e celulares.

Estrutura:

Cabeçalho com o nome da barbearia e menu de navegação.

Seção inicial com uma frase de impacto e botão para agendar horário.

Seção de serviços com cortes de cabelo, barba e corte + barba, incluindo preços fictícios.

Galeria de imagens.

Endereço e horário de funcionamento fictícios.

Botão de contato pelo WhatsApp com um número claramente identificado como exemplo.

Use imagens adequadas ao tema, mantenha o visual organizado e garanta que os botões e links funcionem quando possível.

Não crie login, banco de dados ou sistema de pagamentos. Quero apenas um site de apresentação para um pequeno negócio.
